# Concept-Based Explanations for Dermoscopic Melanoma Classification

> A corrected concept annotation dataset, a hard CBM with stop-gradient, and SOFI-based sparse explanations for melanoma vs. melanocytic nevus classification using dermoscopic images from HAM10000.

---

## Overview

This repository accompanies the paper *Annotation Integrity, Concept Bottleneck Models, and Sparse Explanations for Dermoscopic Melanoma Classification*. The work has three main contributions.

**Contribution 1 — HAM3611C10.** The original annotation schema of Chanda et al. (2024) for the HAM10000 dataset contains four categories of structural problems: diagnosis-informed annotation, pattern-complexity flags that record annotation absence rather than lesion morphology, within-class mutually exclusive concept pairs encoded as independent binary variables, and gestalt flags that act as indirect class labels. HAM3611C10 corrects all four by introducing a revised schema of 10 nominal concepts that satisfy morphological grounding, logical consistency, and non-trivial within-class variation.

**Contribution 2 — Hard CBM with stop-gradient.** A hard Concept Bottleneck Model (CBM) jointly trains a backbone feature extractor, ten concept prediction heads, and a label classifier. A stop-gradient operator applied at the bottleneck prevents the label loss from propagating into the backbone or concept heads, preserving the semantic integrity of the concept representations. The model is benchmarked across 19 backbone architectures and a full-factorial ablation study over four training factors.

**Contribution 3 — SOFI-based explanations.** The Sparseness-Optimized Feature Importance (SOFI) explainer [1, 2, 3] identifies the minimal concept subset whose joint removal reverses the predicted diagnosis. A Gradio web interface renders these explanations as clinician-readable text enriched with dataset prevalence statistics.

## Architecture

The figure below depicts the hard CBM with stop-gradient used in this work. An input image passes through a backbone to produce a feature vector. Ten separate concept heads predict logits for each dermoscopic concept, which are converted into hard one-hot vectors via argmax. The stop-gradient operator at the bottleneck ensures that the label classifier and its loss do not influence the backbone parameters.

## Dataset

HAM3611C10 contains 3,611 biopsy-verified dermoscopic images selected from [HAM10000](https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/DBW86T), each annotated with the 10 revised nominal concepts below.

| Concept | States |
|---|---|
| Reticular lines | absent, present |
| Eccentric structureless area | absent, present |
| Peripheral dots and globules | absent, present |
| Grey structures | absent, present |
| White structures | absent, present |
| Follicular invasion | absent, present |
| Vessel pattern | absent, monomorphic, polymorphous |
| Pseudopods and radial lines | absent, entire circumference, partial circumference |
| Acral pattern | absent, furrows, ridges |
| Scar pigmentation | absent, confined to scar, extends beyond scar |

The dataset metadata file is `meta/clean_concepts_dataset_symbolic.csv`. The split follows the original 3,411/200 train/test partition, with all images from the same lesion and the same patient confined to a single split to prevent data leakage.

## Usage

### Training

All hyperparameters are set through the `Config` class at the top of the notebook. The key parameters are listed below.

| Parameter | Default | Description |
|---|---|---|
| `BACKBONE` | `efficientnet_b0` | Backbone architecture name |
| `BATCH_SIZE` | 16 | Training batch size |
| `EPOCHS` | 20 | Maximum training epochs |
| `LEARNING_RATE` | 1e-4 | Initial learning rate |
| `WEIGHT_DECAY` | 1e-3 | L2 weight decay applied to backbone only |
| `L1_LAMBDA` | 1e-3 | L1 penalty on the first classifier layer |
| `LAMBDA1` | 1.0 | Concept loss balancing coefficient |
| `LAMBDA2` | 1.0 | Label loss balancing coefficient |

To train with the default configuration, run the training cell of the notebook or call:

```python
build_model()
```

The best checkpoint, selected by validation label F1, is saved to `models/cbm_model_{BACKBONE}.pth`.

### Supported Backbones

The following 19 architectures are supported out of the box.

```
EfficientNet  : efficientnet_b0 through efficientnet_b7
DenseNet      : densenet121, densenet161, densenet169, densenet201
ResNet        : resnet18, resnet34, resnet50, resnet101, resnet152
Wide ResNet   : wide_resnet50_2, wide_resnet101_2
```

### Explanation Interface

After training, load the saved checkpoint and launch the Gradio web interface from the explanation cell:

```python
demo.queue(max_size=12).launch(share=False, inbrowser=True)
```

The interface accepts a dermoscopic image upload and returns the MoRF/LeRF degradation curves along with a concept ranking. When a valid `chatgpt_api_key.txt` is present, a three-section clinician-readable text explanation is also generated. SOFI settings (max iterations and patience) and the GPT model can be configured through the UI.

## Results Summary

The table below reports the best-performing architectures across label and concept fidelity metrics on the held-out test set of 200 images.

| Backbone | Label Acc. | Label F1 | Concept Acc. | Concept F1 |
|---|---|---|---|---|
| EfficientNet-B0 | **0.870** | **0.870** | 0.853 | 0.704 |
| ResNet-18 | 0.860 | 0.860 | 0.855 | 0.734 |
| ResNet-152 | 0.850 | 0.848 | **0.879** | **0.768** |
| DenseNet-201 | 0.845 | 0.844 | 0.870 | 0.766 |

EfficientNet-B0 achieves the strongest diagnostic performance while remaining the most parameter-efficient option. ResNet-152 leads in concept fidelity at the cost of a substantially larger model. Backbone weight decay is the most consistent training factor, improving both label and concept performance simultaneously.

## SOFI Explanation Analysis

SOFI explanations were computed for all 174 correctly classified test images (85 melanoma, 89 nevus). For melanoma, *peripheral dots and globules* = present dominates with a SOFI score of 73.58 and appears as the top-ranked concept in 95.3% of correctly classified melanoma images. *Vessel pattern* = polymorphous and *white structures* = present form a secondary tier, with scores of 28.00 and 25.00, respectively. Most melanoma predictions are driven by four concepts on average.

For nevus, all five concept states appearing in the top-k explanations are absence states. *Peripheral dots and globules* = absent, *scar pigmentation* = absent, *white structures* = absent, and *grey structures* = absent each appear in more than 92% of correctly classified nevus images, with a mean concept head confidence above 0.94.
